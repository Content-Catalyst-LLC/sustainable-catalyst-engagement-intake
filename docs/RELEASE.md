# Release Notes — v0.1.0

## Purpose

Establish the secure private-record foundation before exposing public contact forms or accepting documents.

## Included

- Private tables
- Status model
- Inquiry types
- Capabilities and roles
- Admin list/detail screens
- Internal notes
- Status history
- Privacy tools
- Authenticated REST foundation
- Diagnostics
- Retention defaults
- Safe uninstall behavior

## Intentionally deferred

- Public forms
- Physical file uploads
- Notifications
- Sender portal
- Scheduling
- Proposals
- Analytics
- Automated retention

This sequencing reduces the risk of adding public data collection before permissions, privacy, storage, and audit boundaries exist.
