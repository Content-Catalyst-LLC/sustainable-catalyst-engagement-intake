Workflow Core notes
- No new public shortcode is required.
- Workflow Core is private and capability-gated.
- Read-only resources are available through authenticated REST routes.
- Target plugins register internal adapters programmatically.
- No arbitrary webhook URL or inbound command endpoint is included.
