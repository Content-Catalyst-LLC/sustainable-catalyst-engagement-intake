# Changelog

## 0.1.0 — Private Inquiry Records and Plugin Foundation

- Added dedicated `sc_ei_inquiries` table.
- Added dedicated `sc_ei_attachments` metadata table.
- Added dedicated `sc_ei_audit_log` table.
- Added private reference numbers and UUIDs.
- Added twelve inquiry statuses.
- Added ten inquiry categories.
- Added administrator, Engagement Manager, and Engagement Reviewer permissions.
- Added private inquiry list and detail screens.
- Added status changes and private internal notes.
- Added authenticated REST diagnostics and inquiry reads.
- Added WordPress privacy exporter and eraser.
- Added retention defaults and conservative uninstall behavior.
- Added diagnostics, documentation, tests, packaging, and release scripts.
- Deliberately excluded public forms and physical file uploads from this foundation release.
